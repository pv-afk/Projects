# Projects

Прикладные проекты по Machine Learning и анализу данных: кредитный скоринг, ранжирование, сопоставление товаров, прогнозирование временных рядов и аналитика ИТ-портфеля. Каждая папка — самостоятельный проект со своим README, данными, ноутбуком и `requirements.txt`.

Автор — Павел Чиркин. Профиль: [github.com/pv-afk](https://github.com/pv-afk)

## Проекты

| Проект | Задача | Методы | Результат |
|---|---|---|---|
| [Кредитный скоринг](credit-scoring/) | Прогноз исхода кредитной заявки (4 класса) по 51 336 клиентам | Logistic Regression, XGBoost, imbalanced-learn, RandomizedSearchCV | XGBoost: macro-F1 0.71, accuracy 0.80 на отложенной выборке (LogReg: 0.50 / 0.56) |
| [Приоритизация обращений](lead-prioritization/) | Ранжирование обращений по вероятности целевого действия за 5 дней (Avito DS Bootcamp) | LightGBM, CatBoost, временные признаки без утечек | Daily AP 0.760 на локальной отложенной выборке (+0.020 к базовой модели) |
| [Сопоставление аптечных товаров](pharmacy-analysis/) | Поиск одинаковых товаров в трёх прайс-листах и сравнение цен | Регулярные выражения, символьные N-граммы, коэффициент Жаккара | Лучший F1 0.69 (5-граммы, порог 0.50) |
| [Прогноз средней зарплаты](average-salary/) | Прогноз ряда из 399 месячных наблюдений на 36 месяцев | Box-Cox, дифференцирование, auto_arima, SARIMAX | SARIMAX(6,1,2)(0,1,0)[12], прогноз на 36 месяцев |
| [Прогнозирование ИТ-затрат](cost-prediction/) | Анализ исполнения ИТ-бюджета и прогноз расходов | SARIMAX, Linear Regression, XGBoost | Сравнение статистического и ML-прогноза |
| [Портфель ИТ-проектов](it-portfolio/) | Отбор 200 инициатив по ROI, риску и стратегической ценности | Value Index, линейная оптимизация (SciPy) | Портфель при бюджетном ограничении 15 млн ₽ |
| [Цифровая зрелость](it-strategy/) | Оценка зрелости подразделений и приоритеты ИТ-инвестиций | Агрегация опроса, корреляционный анализ | Классификация подразделений по уровню зрелости |

Метрики взяты из сохранённых выводов ноутбуков; для приоритизации обращений — из README проекта (данные соревнования в репозиторий не входят).

## Запуск

```bash
cd credit-scoring            # или любая другая папка проекта
pip install -r requirements.txt
jupyter notebook
```

Данные лежат рядом с ноутбуками, кроме проекта приоритизации обращений — инструкция в его README.
